<h3 align="center">M-Maps - Application for the Deutsche Bahn to keep track of their railways</h3>

  <p align="center">
    M-Maps is a collaborative project implemented as part of a university module. The goal of the project was to develop a web application that helps Deutsche Bahn to keep a detailed record of railway conditions while facilitating the creation and tracking of repair orders. The application enables workers to easily visualize the state of the railways for different routes, thereby improving the maintenance.

## What I implemented

I individually implemented the following features: 
* Creation, editing, and deletion of repair orders.
* Login and registration functionality.
* A dynamic map, developed in pair programming with Janik Thiedke, which included various features such as regional filtering, heatmap filtering, weather information overlays, and data point visualization. This component was the main focus of the work and the most challenging part of the web application.

In addition, I managed commits and branch merges with a teammate and provided support to my group members. This project was a lot of fun, and my enthusiasm drove me to go above and beyond to pass the module.
